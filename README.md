# Reinforcement Learning Beginner Tutorial

This is my attempt to learn reinforcement learning as a beginner.

## Prerequisites

DISCLAIMER: I'm running all of the codes in Ubuntu 24.04 using Windows Subsystem for Linux, so some adjustments for Windows and Mac OS users _might_ be needed.

- [Pixi by prefix.dev](https://pixi.prefix.dev/)
- [Ruff extension for Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=charliermarsh.ruff): optional, but if you want to run the code formatting, this is the one I use.

## Run the code

Run the defined tasks in `pixi.toml`, e.g. `pixi run mountain_car_train`.
